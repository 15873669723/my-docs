## 实践体会

通过本次实践，我学会了使用 Markdown 编写技术文档，并借助 MkDocs 将其构建成静态网站。最让我印象深刻的是 GitHub Actions 的自动化部署——只需修改文档并推送，网站就会自动更新，这让我理解了 CI/CD 在文档发布场景中的应用。
