# API 参考

以下接口仅用于文档展示，不提供真实服务。

## 查询文档列表

- 请求方法：GET
- 请求路径：/api/docs
- 功能：返回文档条目列表。

### 返回示例

```json
{
  "items": [
    {"id": 1, "title": "使用指南"},
    {"id": 2, "title": "关于本项目"}
  ]
}
```

### 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | int | 文档唯一标识 |
| title | string | 文档标题 |

## 个人理解

虽然本项目不开发真实后端，但通过编写 API 文档练习了 RESTful 接口的描述方式，包括请求方法、路径、参数和返回结构，为后续实际开发打下基础。
